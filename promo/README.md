# 宣传片

`dsh-archive-trash` 的 3 分钟宣传片，纯程序化渲染（Pillow 逐帧 + ffmpeg 编码），不依赖任何外部素材。

| | |
|---|---|

| 时长 | **3 分 00.00 秒** |

| 帧率 | 30 fps |
| 编码 | H.264 (High) / yuv420p / CRF 20 |
| 大小 | 约 3.9 MB |

## 分镜

| 时间 | 段落 | 内容 |
|---|---|---|
| 0:00 – 0:26 | **开场** | 「你的 sessions/ 里住着一窝僵尸」—— 背景是漂浮的会话目录，右下角计数滚动 |
| 0:26 – 1:00 | **痛点** | 还原真实的会话 `...` 菜单：置顶 / 重命名 / 分叉 / **归档** / 复制 ID —— 「归档 ≠ 删除」 |
| 1:00 – 1:44 | **功能** | 三小节：① 行内删除 ② 批量清空 ③ 回收站还原 |
| 1:44 – 2:22 | **安全** | 「它不做什么」四张卡片 + 磁盘布局代码块 |

底部全程有进度条和段落名。

## 重新渲染

```sh
pip install pillow imageio imageio-ffmpeg
python render_promo.py
```

约 90 秒渲染完 5400 帧。

脚本会自动找到 `imageio_ffmpeg` 自带的 ffmpeg 二进制，不需要系统安装 ffmpeg。

## 改内容

文案和分镜都在 `render_promo.py` 里，按 `@scene("名字", 秒数)` 装饰器组织：

```python
@scene("痛点", 34.0)
def scene_pain(d, t, T):
    p = t / T          # 0→1 的本段进度
    ...
```

改时长直接改装饰器的秒数，底部进度条会自动跟着重算。

### 一个渲染上的坑

**每段/每小节的第一帧必须有内容**。

初版所有内容都是 `ease_out(clamp(p / 0.15))` 这种「从 0 淡入」，结果切段瞬间整屏空白——抽帧检查时 75s、105s 全是黑的。

修法是给进入动画一个非零起点：

```python
# ❌ 第一帧 alpha=0
enter = ease_out(clamp(seg_t / 0.12))
# ✅ 第一帧就有 55%
enter = 0.55 + 0.45 * ease_out(clamp(seg_t / 0.10))
```

另外在段落交界处加了 0.45 秒的交叉淡化（`Image.blend`），彻底消除硬切。
